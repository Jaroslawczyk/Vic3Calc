# Перевод на другие языки

**[English version — TRANSLATING.md](TRANSLATING.md)**

Добавить язык — значит скопировать **один файл**. Больше ничего в программе
менять не нужно.

## Три шага

1. Скопируйте `app/lang/TEMPLATE.js` в `app/lang/<код>.js` — например `de.js`,
   `pl.js`.
2. Заполните `code`, `name`, `flag` и переводите.
3. Добавьте одну строку в `app/index.html` рядом с другими языками:
   ```html
   <script src="lang/de.js"></script>
   ```

Откройте рядом `app/lang/en.js` и переводите текст **справа** от двоеточия.
Текст слева менять нельзя — это ключи, по которым программа ищет строки.

Переводить всё необязательно. Непереведённое показывается по-английски, поэтому
даже наполовину готовый перевод уже полезен.

## Два раздела

**`ui`** — строки интерфейса.

```js
'sum.workers': 'человек занято',
'order.levels': '{n} уровней',
```

`{в фигурных скобках}` — подстановки; оставляйте их как есть, программа
подставит настоящие значения.

**`entities`** — названия игрового содержимого, ключ `вид.id`.

```js
'good.coal': 'Уголь',
'building.steel_mills': 'Сталелитейные заводы',
'pop.machinists': 'Машинисты',
```

Любой id можно посмотреть во вкладке «Данные» или в `app/data/`. У английского
этот раздел намеренно пуст — он подставляет поле `name` из файлов данных, —
поэтому здесь берите за образец `ru.js`, а не `en.js`.

## Множественные формы

Английскому нужно две формы, русскому — три, а «1 уровней» сразу выдаёт машинный
перевод. Поэтому значением может быть **объект форм**, а не строка:

```js
// английский
'order.levels': { one: '{n} level', many: '{n} levels' },

// русский
'order.levels': { one: '{n} уровень', few: '{n} уровня', many: '{n} уровней' },
```

Форма выбирается по `{n}`. Встроенные правила есть для английского
(`one`/`many`) и русского (`one`/`few`/`many`). Если вашему языку нужно другое
правило — добавьте его в своём же файле:

```js
V3.i18n.setPluralRule('pl', function (n) {
  var m10 = n % 10, m100 = n % 100;
  if (n === 1) return 'one';
  if (m10 >= 2 && m10 <= 4 && (m100 < 12 || m100 > 14)) return 'few';
  return 'many';
});
```

Обычная строка работает везде, поэтому множественные формы можно вообще
проигнорировать и вернуться к ним позже.

## Как проверить себя

**Настройки → Язык** перечисляет все найденные языковые файлы и показывает,
насколько каждый полон:

```
Deutsch    интерфейс 82% · содержимое 40%
```

Полнота интерфейса меряется относительно английского. **Полнота содержимого
меряется относительно реестра данных** — реального списка товаров, зданий,
методов и технологий, — а не относительно `en.js`, который пуст.

Чтобы получить точный список недостающего:

```bash
node tools/selftest.js
```

Скрипт печатает полноту по каждому языку и называет недостающие ключи. Для
русского там есть проверка; добавьте такую же для своего языка, если хотите,
чтобы тест её сторожил.

## Альманах

Каждое предложение встроенного руководства лежит в разделе `ui` под ключами,
начинающимися с `alm.` — сама *структура* статей находится в
`app/data/almanac.js` и перевода не требует. То есть всё руководство из двадцати
статей переводится в том же единственном файле, что и остальное.

Разобранные примеры внутри него считаются вживую по таблицам данных, поэтому они
верны на любом языке, и трогать их не нужно.
